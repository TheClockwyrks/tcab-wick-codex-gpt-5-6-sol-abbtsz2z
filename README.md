# Wick

Wick is a browser survival game about a lone lamplighter crossing a moth-choked city. You steer the light; the lamplighter's tools fire automatically. Gather fallen embers, build a six-tool and six-trinket loadout, open elite chests, evolve paired tools, and survive the ten-minute night until dawn.

## Run locally

Requires Node.js 20 or newer.

```sh
npm ci
npm run dev
```

Open the URL Vite prints. For a production site, run `npm run build`; the self-contained static output is written to `dist/`. `npm run preview` serves that build locally.

## Controls

- Move: Arrow keys or WASD; the on-screen directional pad supports touch.
- Confirm: Enter or Space; menus also support mouse and touch.
- Back / pause: Escape.
- Mute: M.
- Almanac: use left/right to change tabs and the wheel or up/down to browse.

The game needs no server, account, or network connection after its files are served.
